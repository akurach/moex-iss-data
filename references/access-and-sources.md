## Что проверено на сервисе

Публичные запросы без cookie и авторизации вернули HTTP 200:

- Поиск `SBER`: блок `securities`, первая страница 100 строк, маркер `granted`; результаты включают другие инструменты, поэтому выбор первой строки неверен.
- Спецификация `SBER`: блоки `description` и `boards`, основной торгуемый режим `stock/shares/TQBR` на дату проверки.
- Рыночные данные `SBER/TQBR`: блоки `securities`, `marketdata`, `dataversion`, маркер `denied`; наблюдался разрыв 15 минут между `UPDATETIME` и `SYSTIME`. Это наблюдение одного ответа, не гарантия задержки всех ресурсов.
- История `SBER/TQBR` за 2025 год: первая страница 100 строк, `history.cursor.TOTAL=254`, маркер `denied`. Следовательно, фраза старого PDF о недоступности всей истории без подписки не описывает этот текущий публичный endpoint.
- Дневные свечи за 1–10 января 2025 года: 5 строк, маркер `denied`; `/candleborders` вернул `borders` и `durations`.

Независимая проверка агентом по этому skill: получены все 254 строки дневных итогов SBER/TQBR за 2025 год с `tradingsession=3` (страницы 0, 100, 200), границы 3 января — 30 декабря; повторов ключа SECID + BOARDID + TRADEDATE + TRADINGSESSION нет. Клиент завершил пагинацию по cursor TOTAL. Поиск «Сбербанк» с фильтром stock/shares и свечи также проверены до пустой завершающей страницы. Ограниченная выгрузка проверена на код выхода 3 и `complete=false`.

Локальные проверки [test_iss_get.py](../scripts/test_iss_get.py) покрывают пагинацию с курсором и без, `null`, отсутствующий блок, повтор страниц, изменившийся TOTAL, преждевременный пустой ответ, лимит страниц, структуру строк и ограниченные повторы HTTP-ошибок. Запуск из папки skill: `python3 -B -m unittest discover -s scripts -p 'test_*.py'`. Авторизованный доступ и остальные рынки этим набором проверок не квалифицированы.

Это техническая проверка отдельных публичных запросов, не подтверждение доступа ко всем рынкам, лицензии на распространение или доступа в реальном времени. Значения и доступность могут измениться.

Условия применения проекта и биржевой информации описаны в [DISCLAIMER.md](../DISCLAIMER.md); лицензия на код — [LICENSE](../LICENSE). Публичная доступность ответа не предоставляет права коммерческого использования или распространения данных. Для real-time оформляется подписка MOEX, а для других целей — соответствующие договоры. Сам skill разрешен только для личного некоммерческого использования.

Начинай с публичного запроса. Не требуй учетную запись только потому, что она упомянута в старом PDF. Если нужный ресурс закрыт, сообщи точный статус и проверь действующие условия MOEX.

Руководство 2016 года описывает Basic Auth через `https://passport.moex.com/authenticate`, cookie `MicexPassportCert` и `X-MicexPassport-Marker: granted|denied`. Этот способ авторизации здесь не проверялся. При задаче с подпиской сначала проверь текущую схему; используй лишь учетные данные, явно предоставленные для этой цели, через защищенный секрет или среду выполнения. Не передавай их по HTTP, в query, командной строке или отчете. Само чтение этого skill не разрешает вход в аккаунт или покупку доступа. Встроенный клиент авторизацию не реализует.

## Ошибки и повторные запросы

- 400/404: проверь путь, SECID, режим, параметры и схему. Не повторяй неизменный неверный запрос.
- 401/403: обозначь ограничение доступа; не обходи его и не интерпретируй как отсутствие сделок.
- 429 и временные 500–504: для GET допускается один повтор после паузы; учитывай `Retry-After`. Если сервер требует длительного ожидания, сообщи его вместо частого опроса. После двух неудач остановись с точной причиной.
- Таймаут/сбой транспорта: один ограниченный повтор. Ошибку TLS не обходить отключением проверки сертификата.
- HTML или поврежденный JSON: ошибка получения данных, даже при HTTP 200. Отсутствующий ожидаемый блок не считать пустой выборкой.
- Лимит страниц: частичный результат с явным `complete=false`; продолжение требует осознанного увеличения лимита или разбиения периода.

Клиент проверяет обычную структуру `columns/data`, не поддерживает extended JSON и не делает автоматических денежных расчетов. Его `complete=true` означает завершение пагинации для выбранного запроса, а не доказательство экономической полноты истории за пределами выбранного режима.

При разработке постоянного сборщика дополнительно обрабатывай `dataversion` и `SEQNUM`: версия/последовательность может сброситься на новой торговой дате. Не полагайся на бесконечное возрастание SEQNUM. Справочники можно кешировать в рамках дня; данные о ходе торгов требуют отдельной политики обновления с учетом доступа.
