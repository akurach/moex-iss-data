# Условия использования и отказ от гарантий

## Неофициальный проект

`moex-iss-data` — независимый набор инструкций для AI-агентов и вспомогательный Python-клиент, использующий официально документированный API Информационно-статистического сервера Московской Биржи. Официальным является API биржи, а не этот skill.

Проект не создан, не сертифицирован и не поддерживается ПАО Московская Биржа. Автор не выступает от имени биржи. Наименования MOEX, Московская Биржа и другие обозначения принадлежат соответствующим правообладателям и используются для указания источника данных.

Код, инструкции и оригинальная документация предоставляются только для личного некоммерческого использования на условиях [LICENSE](LICENSE). Публичный исходный код не означает разрешения встроить проект в коммерческий продукт или использовать его при оказании услуг. Для коммерческого использования самого проекта требуется отдельное разрешение его правообладателя.

Разрешение использовать код не дает прав на биржевые данные. Базовый сценарий этого проекта — личное ознакомление с доступной информацией при соблюдении действующих условий биржи. На [странице ISS API](https://www.moex.com/a2193) MOEX ограничивает ознакомительным использованием информацию, получаемую без соответствующего договора. Успешный HTTP-запрос не является лицензией на ее дальнейшее использование.

Для коммерческих задач сначала обратитесь в Московскую Биржу и оформите требуемые подписку и/или договор на ваш сценарий. Отдельно регулируются [использование и распространение данных](https://www.moex.com/ru/datapolicy), а также [автоматизированная обработка для алготрейдинга и риск-менеджмента — Non-display](https://www.moex.com/ru/products/nondisplay). ## Задержка и real-time

В [описании интерфейсов MOEX](https://www.moex.com/a7939) для публичного ISS указан задержанный на 15 минут поток, а доступ в реальном времени требует подписки. Это не гарантия одинаковой задержки каждого поля или endpoint: справочники, исторические итоги, индексы и отдельные информационные продукты могут иметь иной режим доступности.

Проверяйте торговую дату, время данных, `UPDATETIME`, `SYSTIME` и `X-MicexPassport-Marker`. HTTP 200 или маркер `granted` сами по себе не подтверждают свежесть конкретной котировки. Последняя сделка могла состояться значительно раньше времени обновления таблицы. Незакрытые свечи и внутридневные итоги могут изменяться.

Если нужны real-time данные, оформите [подписку на биржевую информацию](https://www.moex.com/ru/orders?realtime) и убедитесь, что выбранный продукт и договор покрывают ваше использование. Клиент в этом репозитории работает с публичными GET-запросами: он не выполняет авторизацию, не подключает подписку и не обходит ограничения доступа.
